# Playbook 13: Customer RFM Segmentation & Behavioral Analytics

## 1. Objective & Scope

Customer segmentation is vital for commercial cosmetics retail in Egypt, where repeat purchase behavior, high-value basket sizes, and promotional responsiveness determine customer lifetime value (LTV).

This playbook details the implementation of **RFM Analysis (Recency, Frequency, Monetary)**:
1. Mathematical definition of Recency, Frequency, and Monetary metrics.
2. A transparent, quantile-based scoring methodology ($1$ to $5$) that avoids arbitrary heuristic cutoffs.
3. Defining canonical customer segments: **`Champions`**, **`Loyal Customers`**, **`Potential Loyalists`**, **`At Risk`**, and **`Lost Customers`**.
4. Authoring dynamic DAX measures and dimension models to power the Customer Analytics report page.

---

## 2. RFM Dimension Definitions

For every active customer $c$ evaluated as of an analysis reference date $T$ (e.g. December 31, 2025):

1. **Recency ($R$):** Days elapsed since customer $c$'s most recent completed order.
   $$R_c = \text{DateDiff}(\text{Max}(\text{OrderDate}_c), T, \text{Day})$$
   *(Lower days = More recently active = Higher engagement score).*

2. **Frequency ($F$):** Total count of distinct completed orders placed by customer $c$.
   $$F_c = \text{DistinctCount}(\text{OrderID}_c)$$
   *(Higher count = More frequent shopper).*

3. **Monetary ($M$):** Total net sales spend generated by customer $c$.
   $$M_c = \sum \text{NetSales}_c$$
   *(Higher total EGP = Higher financial value).*

---

## 3. Empirical Quintile Scoring Methodology

To avoid arbitrary cutoffs (e.g., guessing that 100 days is "at risk"), we partition the $25,000$ customer population into **quintiles ($20\%$ tiers)**:

| Score | Recency ($R$) Quintile (Days Since Last Order) | Frequency ($F$) Quintile (Distinct Completed Orders) | Monetary ($M$) Quintile (Total Net EGP Spend) |
| :---: | :--- | :--- | :--- |
| **5 (Top 20%)** | $1 - 45\text{ days}$ (Purchased recently) | $\ge 28\text{ orders}$ | $\ge 24,000\text{ EGP}$ |
| **4** | $46 - 90\text{ days}$ | $20 - 27\text{ orders}$ | $17,000 - 23,999\text{ EGP}$ |
| **3** | $91 - 150\text{ days}$ | $14 - 19\text{ orders}$ | $11,500 - 16,999\text{ EGP}$ |
| **2** | $151 - 240\text{ days}$ | $8 - 13\text{ orders}$ | $6,000 - 11,499\text{ EGP}$ |
| **1 (Bottom 20%)** | $> 240\text{ days}$ (Dormant) | $1 - 7\text{ orders}$ | $< 6,000\text{ EGP}$ |

---

## 4. Segment Mapping Matrix

By combining the $R$, $F$, and $M$ scores, customers are classified into 5 actionable business segments:

| RFM Segment | Composite Scoring Rule | Customer Persona in Egyptian Cosmetics | Recommended Commercial Action |
| :--- | :--- | :--- | :--- |
| **Champions** | $R \in [4, 5]$ AND $F \in [4, 5]$ AND $M \in [4, 5]$ | High-spending brand advocates who buy new skincare drops and fragrances regularly. | Early access to new product launches; VIP loyalty rewards; no discounts needed. |
| **Loyal Customers** | $R \in [3, 5]$ AND $F \in [3, 5]$ AND $M \ge 3$ | Consistent repeat buyers across body care and everyday staples. | Cross-sell higher-margin categories (e.g. gift sets); personalized routine recommendations. |
| **Potential Loyalists** | $R \in [4, 5]$ AND $F \in [1, 2]$ | Recent first-time or second-time shoppers with high potential. | Onboarding nurture sequence; offer 10% discount on second repurchase within 30 days. |
| **At Risk** | $R \in [2, 3]$ AND $F \ge 3$ AND $M \ge 3$ | Formerly active buyers who have not purchased in 4-8 months. | Reactivation campaigns; personalized SMS/WhatsApp offers; win-back discounts. |
| **Lost Customers** | $R = 1$ AND $F \le 2$ | Dormant customers with no purchases in over 8 months. | Cost-efficient automated email remarketing; do not spend paid SMS budget. |

## 5. DAX Implementation

In `_Measures` under display folder **`03 Customer & AOV`**:

### 1. Customer Level Base Measures
```dax
Customer Last Order Date = 
CALCULATE(
    MAX(fact_sales[order_datetime]),
    fact_sales[order_status] = "Completed"
)
```

```dax
Customer Recency Days = 
VAR LastOrder = [Customer Last Order Date]
VAR AsOfDate = MAX(dim_date[Date])
RETURN
    IF(
        NOT ISBLANK(LastOrder),
        DATEDIFF(LastOrder, AsOfDate, DAY),
        BLANK()
    )
```

```dax
Customer Frequency = 
CALCULATE(
    [Completed Orders],
    ALLEXCEPT(dim_customer, dim_customer[CustomerKey])
)
```

```dax
Customer Monetary = 
CALCULATE(
    [Net Sales],
    ALLEXCEPT(dim_customer, dim_customer[CustomerKey])
)
```

---

### 2. Dynamic RFM Segment Classification Measure
```dax
Customer RFM Segment = 
VAR R_Days = [Customer Recency Days]
VAR F_Count = [Customer Frequency]
VAR M_Spend = [Customer Monetary]

VAR R_Score = 
    SWITCH(
        TRUE(),
        ISBLANK(R_Days), BLANK(),
        R_Days <= 45, 5,
        R_Days <= 90, 4,
        R_Days <= 150, 3,
        R_Days <= 240, 2,
        1
    )

VAR F_Score = 
    SWITCH(
        TRUE(),
        F_Count >= 28, 5,
        F_Count >= 20, 4,
        F_Count >= 14, 3,
        F_Count >= 8, 2,
        1
    )

VAR M_Score = 
    SWITCH(
        TRUE(),
        M_Spend >= 24000, 5,
        M_Spend >= 17000, 4,
        M_Spend >= 11500, 3,
        M_Spend >= 6000, 2,
        1
    )

RETURN
    SWITCH(
        TRUE(),
        ISBLANK(R_Score), "No Orders",
        R_Score >= 4 && F_Score >= 4 && M_Score >= 4, "Champions",
        R_Score >= 3 && F_Score >= 3 && M_Score >= 3, "Loyal Customers",
        R_Score >= 4 && F_Score <= 2, "Potential Loyalists",
        R_Score <= 3 && F_Score >= 3 && M_Score >= 3, "At Risk",
        R_Score == 1 && F_Score <= 2, "Lost Customers",
        "Hibernating"
    )
```

---

### 3. Segment Aggregator: `[RFM Customer Count]`
To show the distribution of customers across segments in report charts:

```dax
RFM Customer Count = 
COUNTROWS(
    FILTER(
        VALUES(dim_customer[CustomerKey]),
        [Customer RFM Segment] = SELECTEDVALUE('ref_rfm_segments'[SegmentName])
    )
)
```
*(Where `'ref_rfm_segments'` is a 5-row reference table containing `Champions`, `Loyal Customers`, `Potential Loyalists`, `At Risk`, `Lost Customers`).*

## 6. Visualization & Business Application

In **Page 3 (Customer Analytics)**:
1. **Treemap or Clustered Column Chart:** Display `[RFM Customer Count]` and `[Net Sales]` by `Customer RFM Segment`.
2. **Scatter Plot:** X-axis = `[Customer Recency Days]`, Y-axis = `[Customer Monetary]`, Bubble Size = `[Completed Orders]`, Legend = `Customer Segment`.
3. **Cross-filtering Action:** Clicking **"At Risk"** immediately filters the top customer table to show names, phone numbers, and preferred beauty categories (Skincare, Fragrance), enabling CRM teams to trigger instant targeted SMS promotions.
